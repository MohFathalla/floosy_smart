# Floosy - Expense Tracker

A simple expense tracker built with Java and Spring Boot.

**Technologies:** Java, Spring Boot, HTML, CSS, JavaScript.

## How to Run

Requires Java and Maven.

1. Clone the repository.
2. Open the project in your IDE.
3. Run `FloosyApplication.java` or use:

```bash
mvn spring-boot:run
```

4. Open `http://localhost:8080` in your browser.
